The building blocks behind every student screen. Each maps to one Flutter widget in core/ui; screens compose them and never set a colour or radius themselves.

Buttons

Primary is teal, one per screen, pinned to the bottom. Quiet = sunken. Tonal = an optional next step. Text buttons for edit and destructive.
